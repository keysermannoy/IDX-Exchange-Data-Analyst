# IDX Exchange – Real Estate Data Analytics

## Project Overview

This project focuses on preparing, validating, cleaning, and analyzing residential real estate listing and transaction data.

The workflow includes processing residential property records, integrating mortgage rate information, engineering analytical features, and exploring geographic and school district relationships.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- FRED Economic Data

## Project Workflow

1. Monthly data aggregation
2. Dataset validation and quality checks
3. Data cleaning and preprocessing
4. Feature engineering
5. School district enrichment and analysis

## Feature Engineering

Examples of engineered variables include:

- Price per square foot
- Close-to-original-list-price ratio
- Listing-to-contract duration
- Contract-to-close duration
- Year and month indicators

## Data Privacy

Raw datasets and processed MLS records are not included in this public repository.

Ongoing project. Additional analysis and documentation will be added as the project progresses.
